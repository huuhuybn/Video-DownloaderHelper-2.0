## 🔍 Smart Video Detection

Multiple detection methods working together:

- **Network Monitoring** — Intercepts video/audio HTTP requests in real-time
- **DOM Scanning** — Finds `<video>` and `<audio>` elements on the page
- **HLS Detection** — `.m3u8` playlist streams
- **DASH Detection** — `.mpd` manifest streams
- **Dynamic Detection** — Watches for dynamically loaded content via MutationObserver

> Toolbar icon turns **colored** (🟡🔴🔵) when media is detected.
