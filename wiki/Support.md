## 🔍 Troubleshooting

### Video not detected?

1. **Play the video** — detection starts when the video begins loading
2. **Skip ads** — the extension may pick up ad media first
3. **Click "Force Detection"** in the popup
4. **Refresh the page** — try a clean reload
5. **Check DRM** — some streaming services use DRM and cannot be downloaded

### Download button grayed out?

- Extension icon turns **colored** (🟡🔴🔵) when media is detected
- Gray icon = no media detected on this page
- Does not work on browser internal pages (`chrome://`, `about:`)

### Download fails?

1. Check internet connection
2. Try a lower quality
3. Check disk space
4. Disable conflicting extensions
5. Update to the latest version

### Extension missing from toolbar?

1. Go to `chrome://extensions/`
2. Make sure it's **enabled**
3. Click the puzzle icon 🧩 → **Pin** the extension
